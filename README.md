# RAREngine

A lightweight custom 3D game engine built with C++ and raylib.

> Designed to Learn.
> Built from Scratch.

---

## Features

- Custom rendering pipeline
- Entity and scene management
- Transform system
- Camera controller
- Input and time system
- Asset management
- Mesh and material abstraction
- Basic world system
